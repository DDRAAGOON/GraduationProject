# Jobito Backend

Express API for recruitment workflows (user/company/jobs/applications/messages/notifications).

## Run locally

1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env`
4. `npm run dev`

Server URL: `http://localhost:4000`

## Demo credentials

- User: `user@jobito.com` / `12345678`
- Company: `company@jobito.com` / `12345678`

## Deploy to Render

- `render.yaml` is already configured at repo root.
- Push repository and create a new Render Blueprint deployment.
